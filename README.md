## 部署

1. 在现有应用管理页确认 GitHub 仓库、分支、入口文件路径。
2. 备份现有入口程序与依赖文件。把本目录的 `app.py`、`requirements.txt`、`web/`、`.streamlit/config.toml` 提交到相应仓库。若现有入口不是 `app.py`，将这里的入口内容放到实际入口路径，并确保 `web/` 与该入口同目录。
3. 保持原应用和域名，不新建应用。仓库提交后等待 Streamlit 自动重新部署。
4. 打开原网址检查标题、版本 3.1.0、导入、单月/全部月份计算、四表下载、逐卡依据。

本更新包不含学生原始数据、名册、真实筛选结果、访问密钥或本机缓存。不要把这些文件提交到仓库。

## 工作方式与隐私

Streamlit 仅提供页面和同源程序资源。组件中的 Web Worker 使用本地随包分发的 Pyodide/SQLite/XlsxWriter 在浏览器内处理文件；没有服务器上传接口，没有把文件、卡号或结果传回 Python。关闭或刷新页面后重新导入。程序不依赖 chatgpt.site 或外部计算 CDN。

分类依据是源表的“消费场所类别”，先整理当月三类实际消费记录，再比对三表共同卡号，严格应用六项阈值；缺少某类记录不补零入选。餐饮次数 >50 且总额 <750，饮品次数 <10 且总额 <50，商服次数 <10 且总额 <200。金额以分累计。输出与原模板四表对应。

`python -m pip install -r requirements.txt` 后运行 `python -m streamlit run app.py` 可本地调试。普通使用者只需打开部署后的网址，不需安装 Python。
